# 统计窗口与 QR 技术债修复

日期：2026-10-04。基线：`1d942a9ff4fdbb5d5a84a5d28ac215ad7d3dc620`。

## 改动与数值边界

- 滚动 sum 在大值移出后按可逆二次幂缩放与精确双分量累加恢复；有限归零但仍含小值的尾窗只在受限资格下重建。动态缩窗把资格标志合并到整轮移除结束后扫描一次，保持线性工作；近值差分捷径不会覆盖已经恢复的尾和。same-bar undo、discard 与 checkpoint 仍按原聚合值赋回。
- correlation/covariance 对派生乘积溢出、分母溢出/下溢及严重消去使用缩放居中计算；筛选按窗口长度估计累加影响，仍是启发式而非整个历史滚动误差的严格上界；真实缺失源仍是 NA。常量证明用相邻变化计数 O(1) 维护，避免 constant covariance 新增全窗扫描；有限常量的旧浮点残差保留。front、两个邻居、middle、last 的五个观察值只用于保守排除扫描，余下候选仍需完整居中资格。
- ready 全零窗口的 variance/stdev 跳过平方差扫描；unbiased length<2 仍未定义。其他方差、WMA/HMA 和普通 correlation 仍扫描窗口。
- 2×2 等对角、异号非零 offdiag 的实根判定在容差对称性之前执行，避免微小/次正规乘积下溢伪造实根；QR 仅在有限矩阵逐元素位相同时提前停止，并走原实根/复根分类。

没有改已有 golden、结构阈值、公开协议或主机边界。普通兼容与有意数值修正使用独立分母；代码仍是确定、可独立运行的 Pine core。

## 本机受控性能与空间

74 cases、424 fresh processes；每版本通常交替 3 次，输出 staged 归因每版本 1 次。全部原 56 场景、普通控制、48 有效 TA 调用压力、输出流程、HMA 和矩阵工作区场景保留。编译/门禁/正确性/差分结束后开始测量。

相邻变化及 undo 两个 usize 在 64bit 名义增加 16 B/window；实际 HashMap 容量、heap 与 clone 请求增长见全部样本。优化收益和任何慢化项均按场景报告。

## 剩余问题

- `x=1e8+bar_index%257, L=257`：完整同源相关应为 1、方差与协方差 5504，before/after 仍给出协方差 5502、相关约 0.9996366，方差实际画出 5504。长度 37 的前一反例已修，本轮仍未建立整个有限域的数值精度合同。
- 恒定 series `1e308, L=2`：WMA/HMA 的可表示结果应为 `1e308`，before/after 仍 NA；加权乘积中间溢出。一般 variance/stdev、QR 收敛与 pinv 的条件数资格仍待后续。
- forming/策略 checkpoint 仍深复制普通 rolling HashMap 及 VecDeque；长窗口的复制随窗口长度增长。若引入分块 COW，必须先保 realtime/varip/request/策略 rollback 合同。
- Math/Array 等家族仍有字符串派发和表达式树执行；这是源码确认的结构候选，尚未证明扩大 typed opcode 的吞吐收益。

后两项结构候选不等于本轮已测热点。剩余数值诊断单独记录 mathematical failure 与 transport/replica 成功，不混入普通兼容或修复数学分母。

遗留诊断的失败计数包含 snapshot 重复序列化的历史值；最后 snapshot 去重 bar 另列。报告保留全部计数、最后输出、去重 bar、前 16 个失败样本及完整失败列表摘要 SHA，完整重复列表保留在已审计的不可变 raw summary，避免重复嵌入约 6.8 MB。

sum 冷恢复不是任意 f64 的精确求和器：不可逆缩放、第三补偿分量丢失、真实非有限样本和不可表示结果拒绝恢复。三样本中位数是本机描述结果；allocator 请求不含分配器开销，RSS 与累计峰值另计。

最终离线审计独立重读最终与初始基线的 raw stdout/stderr、重算中位数/样本、解析 oracle、校验源/库/探针身份和冻结 tar。superseded 轮只核对不可变 summary、归档源/探针/库身份、计数与 exit，不宣称重新审计其全部 raw；它们不计入最终审计分母。报告未把 duplicated audit metrics 或 artifactChecks 再嵌一遍。精确过程计数与后续诊断分母均见 JSON。
