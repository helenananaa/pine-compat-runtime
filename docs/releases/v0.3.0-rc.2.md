An opt-in release candidate for the independently usable Pine runtime core.
The latest stable release remains **v0.2.0**.

### Changes

- Integrates incremental/realtime streaming, replica and public-result APIs,
  chart/request-time fixes and stricter atomic bar timestamp validation.
- Bounds logical per-bar collection allocations/copies and matrix-kernel work;
  oversized workloads fail with `E_RESOURCE_BUDGET`.
- Reduces sparse paged rollback costs, repeated map lookups and collection/matrix
  scans; caches immutable ALMA coefficients.
- Assigns a unique `0.3.0-rc.2` identity (Python distribution `0.3.0rc2`).

### Downloads and qualification

Official assets are optimized Python wheels for ordinary GIL-enabled CPython
3.10+ on Windows x86-64 and glibc Linux x86-64 (manylinux2014 / glibc 2.17),
plus `manifest.json` and `SHA256SUMS`. Rust, CLI and WASM are available from the
tagged source; separate binary downloads for them are not included.

Fresh Windows/Linux release builds rerun the unchanged 15-case frozen
native/cross-surface plan: 180 complete outputs, including direct Rust,
installed Python, CLI batch/incremental/realtime-history and actual Node/WASM.
Canonical gates pass on both platforms. Official wheels are installed into
clean offline environments and compared against all 15 qualified full outputs;
the Linux wheel also runs inside a glibc 2.17 container.

### Upgrade and known limits

Handle rejected duplicate/older bar timestamps and `E_RESOURCE_BUDGET`.
Defaults are 64 MiB logical collection bytes and 100,000,000 matrix work units
per bar execution. Rust exposes configurable `ResourceLimits`; Python, CLI and
WASM use the defaults. These are not RSS or long-session memory guarantees.

Stable resource qualification remains open. The earlier fixed matrix failed
Linux Python Pivot four-session growth checks (4.288 / 4.578 / 4.456 versus a
limit of four); it has not been requalified for this RC. Hull displayed-PnL
residuals remain open (retained maximum 0.006690 USD). General native live-Tick,
exchange-session calendars, native visual geometry and arbitrary Pine/strategy
compatibility are outside the qualified scope. macOS, ARM, musllinux and
free-threaded CPython are outside the wheel matrix.

Read [migration and limits](https://github.com/helenananaa/pine-compat-runtime/blob/v0.3.0-rc.2/docs/RC2_MIGRATION.md)
and [acceptance evidence](https://github.com/helenananaa/pine-compat-runtime/blob/v0.3.0-rc.2/docs/RC2_ACCEPTANCE_20261006.md).
