This release connects the host-neutral contracts needed for deterministic Pine
strategy observations, authoritative external accounts and causal requested
data. Hosts remain responsible for market data, physical execution and their
own scheduling and persistence.

- Native risk declarations register independently of branch/declaration order;
  repeated rules retain the strictest effective constraint.
- Strategy valuation and sizing support supplied linear contract multipliers
  and exact quantity rules, with explicit metadata and fill receipts.
- Requested-data deltas invalidate dependent contexts and preserve causality;
  provider-only updates do not execute a duplicate chart observation.
- External sessions support historical OHLC tick schedules, persistent realtime
  observations, account feedback, bounded window discovery, atomic event cohorts
  and deterministic rebase/reconstruction. Realtime window reservation does
  not reveal future prices. New realtime dynamic contexts retain admission
  checks.
- Python exposes typed failed request contexts so a host can handle discovery
  without trusting script error text.
- WASM sessions and replicas expose independent owned JSON snapshot readers.
  Reusing a caller-owned byte buffer avoids accumulating complete encoded
  Strings or per-block JavaScript buffers while retaining every output byte.
  Captured snapshots survive source advancement or destruction. The full
  encoded snapshot still occupies memory proportional to output size in WASM.

All four CPython `abi3-py310` platform wheels are promoted byte-for-byte from
successful native CI at source `28f54b97a37422eef5357832bd73fb189b988d85`.
Each promoted wheel is installed and tested again on the release runner. The
release manifest records both the producer source and release commit; a source
comparison rejects changes outside release tooling and qualification documents.
`qualified-inputs.json`, `resource-qualification.json` and `SHA256SUMS` bind the
original artifacts and evidence. This avoids treating a rebuild with different
native bytes as the measured binary.

The finite offline resource qualification covers Windows and Linux across
optimized Rust, installed Python wheels and actual WASM under Node: three frozen
scripts, 1,024/16,384/100,000 historical bars, live tails, one/four independent
interleaved sessions and two fresh repetitions. Every one of the 216 trials must
meet the unchanged budgets and the combined audit must show zero cross-surface
mismatch groups. Numerical limits and observed metrics are recorded in the
resource qualification asset. The four sessions do not measure parallel
throughput. macOS has installed-wheel compatibility evidence, without a macOS
resource measurement.

The semantic full gate at the completed implementation passed 7,999 Rust cases,
2,029 fresh installed-Python cases, strict Clippy, formatting, structural/host
parity and generated WASM/Node checks. The completed snapshot-reader producer
also passes full Linux/Windows CI and all four native wheel jobs. Historical
evidence retains its original source and binary identities.

These checks do not qualify indefinite sessions, arbitrary TradingView/Renko
construction, exchange queue priority, a connected live feed, or any particular
host application's packaged workflow. CandleScope integration and packaged
acceptance are separate deliverables. Free-threaded Python and Linux/Windows
ARM remain outside this wheel set.
