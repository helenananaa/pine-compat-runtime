## 单独保留的工具失败与校准

Linux helper 的首次 CRLF 启动失败发生于 source extraction 和 canonical build/test 之前，wrapper 随后因尝试哈希缺失 gate log 而退出；该记录单独封存。旧 wrapper 原件归档时已加 log guard，故另从已知 predecessor 按当时复制流程重建确切字节，并以 targeted/失败调用两份记录的同一 SHA 验证，明确标记 reconstruction。

独立 baseline 依赖目录首次只保存 147 rlib，缺少 proc-macro/metadata，两个链接尝试以 E0463 退出。辅助归档首次错误读取 UTF-16 日志，断言失败并引起重复链接；随后验证原 147 rlib 未变化，再补齐 164 个 DLL/import-lib/rmeta，最终目录 311 对象。失败记录全部排除，qualified native probe 执行为零。三次成功 before 小样本校准也不计入最终 78。独立 audit 的 helper 断言修复记录另外保留。

## 剩余问题

- 普通大数组仍有 DOM 和 typed 结果共存的峰值成本；后续可研究逐元素消费或直接 typed 反序列化，同时保留错误文本、扩展规则、位值和输出所有权。
- AppendHistory 容量仍扫描历史树；可缓存每节点已分配槽数，完整覆盖 COW、Repeat 展开、插入、压缩和剪枝。完整 profile 仍按对象/快照数遍历。
- 动态 valuewhen 状态仍是普通 VecDeque，Series occurrence 可保留 100 万个条件事件；forming/order-fill checkpoint 的深复制需要专项实测。
- last_changes 的第二份 owned 增量仍存在；存储共享或借用入口需保留现有 owned API、失败回滚和 replica 契约。
- Math/Array 二级字符串分派仍待隔离测量；array get/set 已直接索引参数。一般 WMA/HMA、方差恢复 O(L) 与此前数值资格范围也仍保留。
