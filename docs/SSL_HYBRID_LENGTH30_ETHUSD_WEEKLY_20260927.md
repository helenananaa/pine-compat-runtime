# SSL Hybrid Strategy HMA 30 on ETHUSD weekly history (2026-09-27)

The unchanged public Pine v5 [SSL Hybrid Strategy by kevinmck100](https://www.tradingview.com/script/2it69GUx-SSL-Hybrid-Strategy/) was run in Chrome on `COINBASE:ETHUSD`, `1W`. `SSL1 / Baseline Type` was `HMA`, `SSL1 / Baseline Length` was changed from 60 to 30, `Source` was `close`, and all other script inputs retained their original values. The source is frozen at `.local/ssl-hybrid-length30-ethusd-weekly-20260927/ssl-hybrid-original.pine` (SHA-256 `1b90bead338682dcc17b8c1063637e7b8354c91b35d9d2a741ae41b5274c658c`). The TradingView Inputs and Properties panels, screenshot, chart export, and trade-list export are retained in the same ignored evidence directory. The Properties panel records USD 5,000 starting capital, 10% equity default order size, pyramiding 10, 0.04% commission, zero slippage, default four-tick historical bar detail, and one-tick order delay.

The frozen native chart CSV has 540 rows, beginning 2016-05-23. Its 2026-09-21 row was forming and excluded. The comparison therefore uses **539 confirmed weekly bars through 2026-09-14**. Time and OHLC match an earlier independent ETHUSD weekly export; volume on the final confirmed week was revised from `918445.82114996` to `917799.38115157`, so this run uses the new frozen CSV throughout. `bars-receipt.json` records counts and SHA-256 checksums; `native-chart.csv` hashes to `ffa1e68ec9ca7b35868d1b879d119041956592fd9981ed0441d0a529a651b201`, and `native-trades.csv` to `eb3698e520b1c142dbbb434f4d40e7f39bea02be4867e436b034b0cd6688c4c6`.

All **3,599 nonblank positions** in the eight exported indicator series match the local result at `1e-8` absolute tolerance. The optional second moving average is blank throughout. TradingView's chart CSV flattens false/`na` values in the Candle Size condition to zero; the comparator accounts for that export format. The native strategy report contains **98 closed trades and two open entries**. Every closed trade's entry ID, UTC entry and exit date, displayed entry and exit price, and quantity matches. The two open entries match in ID, entry date, displayed price, and quantity. The largest closed-trade net-PnL difference is `$0.004995`, within the native CSV's cent display precision. There are no runtime diagnostics.

The first local attempt produced five extra long trades in August 2021 while all chart plots still matched. The script first calls `ta.crossover(close, sslDown)` inside its `in_date` conditional on the 2021-08-02 weekly bar. The runtime previously read the prior global chart values for that call, despite the call having no prior evaluation. `ta.cross`, `ta.crossover`, and `ta.crossunder` now retain their own callsite argument history, including rollback state for fill-triggered strategy reevaluation. A focused test covers first conditional invocation and a skipped bar. This follows [TradingView's execution model](https://www.tradingview.com/pine-script-docs/language/execution-model/) for local call histories.

The host-neutral chart contract explicitly supplies `COINBASE:ETHUSD`, `1W`, a `1/100` price grid, and four-decimal quantity precision. The last setting matches the native export's contract quantity grid; omitting it preserved trade dates and prices but caused quantity and PnL differences. The CLI applies input callsite 13 as `30`. Batch, incremental, and realtime-history JSON are byte-identical, SHA-256 `70deb51e001d274cc0ebf2c351f6bf2b14a4b878de82780c84abe52412e2cecf`. The independent native comparison and the local unit suite (`1,975` Rust runtime tests) passed. This qualifies the confirmed historical weekly scope described here; forming-bar and live-tick parity remain unmeasured.

Reproduce from the repository root:

```powershell
python .local/ssl-hybrid-length30-ethusd-weekly-20260927/prepare_bars.py
target/debug/pine-compat.exe run .local/ssl-hybrid-length30-ethusd-weekly-20260927/ssl-hybrid-original.pine --bars .local/ssl-hybrid-length30-ethusd-weekly-20260927/bars-confirmed.csv --chart-symbol COINBASE:ETHUSD --chart-timeframe 1W --chart-price-grid 1/100 --chart-quantity-precision 4 --input-override 13=30 > .local/ssl-hybrid-length30-ethusd-weekly-20260927/local-batch.json
python .local/ssl-hybrid-length30-ethusd-weekly-20260927/compare.py
python .local/ssl-hybrid-length30-ethusd-weekly-20260927/verify_modes.py
```

For `verify_modes.py`, run the same command with `run-incremental` and `run-realtime-history`, writing `local-run-incremental.json` and `local-run-realtime-history.json` respectively.
