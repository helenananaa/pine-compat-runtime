# Historical scalar `request.security_lower_tf` (2026-09-25)

TradingView documents `request.security_lower_tf()` as returning an array of requested expression values from all available intrabars in each chart bar, ordered by intrabar time. A chart bar without available intrabars receives an empty array. See the official [Other timeframes and data](https://www.tradingview.com/pine-script-docs/concepts/other-timeframes-and-data/) documentation.

The runtime now supports the three-positional-argument scalar subset in Pine v5/v6 historical execution. The host provides timestamped bars for the lower or equal requested timeframe through the existing request data provider. Each request callsite evaluates its expression and history in a separate requested context, then builds a fresh typed array for the current chart interval. `host_requirements` exposes the callsite with a `sameOrLower` timeframe relation. The core does not fetch or persist market data.

The tracked fixture `tests/fixtures/request/security_lower_tf_scalar.pine` and focused runtime tests cover ordered 1-minute closes within 5-minute chart bars, missing minutes, an empty interval, cross-chart-bar `ta.change` state, an equal-timeframe chart-context request, and rejection of a higher requested timeframe. The CLI fixture run with `ibm_5m.csv` and host-provided `ibm_1m.csv` returns plot series `[3,2]`, `[20,23]`, and `[22,24]` without diagnostics. The result is retained as ignored `.local/community-coverage-20260923/lower-tf-cli-scalar-20260925.json`.

This is a partial capability. Optional request policies other than named `calc_bars_count`, collection expressions, and provider-backed forming updates remain rejected. No TradingView numerical export for this new subset has been compared yet. The locked five-package test result is in ignored `lower-tf-scalar-five-package-tests-20260925.log`; the WASM/Python binding test result is in `lower-tf-scalar-bindings-tests-20260925.log`. The latter also required correcting stale WASM request expectations for the initial values of `ta.barssince`, `ta.highestbars`, and `ta.lowestbars`. Tuple and bounded-history support were added afterward and are documented separately.
