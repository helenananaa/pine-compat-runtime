## 实现与契约

SharedDeque 的分页表示把首尾页独立保存，中间目录只保存完整的 128 项内页。未跨页边界的共享端点写入只复制被修改页；满页迁移和多内页过期仍会复制共享目录。单页或双页不保留空目录，唯一内页过期直接取得页引用，避免复制马上丢弃的目录。

单页同时存在前后已移除物理项时仍保留逻辑尾界；新前页、尾页迁移、缩小再扩大不重新暴露旧项。索引和 nth/nth_back 直接定位，fold 仍按原逻辑顺序使用同一个累加器，没有页级求和重组。容量、精确 Float bits 恢复、检查点和分支隔离契约不变。

新增 8 个独立 VecDeque 回归，覆盖共享端点/目录身份、单/双/多页迁移、双端 ghost、边界过期、混合双向迭代与 fold、多个检查点、Weak 生命周期、零尺寸元素和 ±0/NaN 精确位恢复；定向 27 项通过。既有测试名称、语义 oracle 和结构阈值未放宽，生产文件 613 行，model helper 上限仍为 800。
