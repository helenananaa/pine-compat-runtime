## 仍需处理的技术债与边界

- WMA、variance/stdev/deviation 仍按原浮点顺序扫描。普通递推改变末位结果：WMA 的 `[1.9740217299521614, 0.49079091230814775, -1.9243273225775828]` 加入 `0.7080337531490288`，扫描与 `W-S+3x` 相差 2 ULP；variance `[1,2,4]` 的平方差求和为 `4.666666666666667`，`Q-S*mean` 为 `4.666666666666664`。需要独立数值资格验证，不能修改黄金数据掩盖。
- RCI/mode 仍为排序算法；大窗口长期保留最大 scratch 容量，检查点后首次使用需要重新分配。
- 长窗口极值用额外候选状态换扫描时间。单调输入可保留 O(L) 候选；动态长度、稀疏重建、值为零的精确兼容 fallback 可以 O(L)。树路径查找/裁剪以及节点释放只提供摊销收益，不声称严格最坏更新时限。
- 递归 HIR 执行、各内建家族内部字符串分派和更深层参数查询仍存在；本轮 prepared 快路径主要覆盖 math，并未完成字节码/VM 改造。
- 矩阵 pinv 更广泛的数值稳定性/SVD 资格仍未完成。
- owned Rust result()、完整 JSON String、Python 对象树和解析后的 JSON 树仍需要输出规模内存；单个很大的 table/polyline snapshot、元数据和诊断也可能分配较大缓冲。逐 drawing 字段的小 String 分配仍是下一步候选。

分配值是请求字节，不包含分配器开销，也不表示 realloc 短暂双缓冲的真实峰值。RSS 是 Windows 工作集；process peak RSS 自进程启动累计，无法当作重置后的阶段峰值。分阶段 probe 会有意保留 prior stage 输出，不能与独立 pipeline 的峰值混为一谈。
