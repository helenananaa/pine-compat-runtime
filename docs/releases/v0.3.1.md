Adds two host-neutral interfaces previously available only in an unpublished
extension branch. Official 0.3.0 lacked them, preventing dependent hosts from
upgrading their complete execution package.

- Python Program.run_external and Rust external-account APIs evaluate Pine
  against supplied authoritative account frames and emit order intents.
  Matching stays in the host; native broker execution and ledger output are
  disabled in this mode.
- Python Program.historical_session supports fixed-horizon advance, cursor and
  independent fork states for replay and seeking. It preserves batch endpoint
  semantics, requested data, magnifier, clocks, overrides, session windows and
  calc_bars_count behavior.
- External position history uses feedback; entry quantity expressions execute
  once. Failed historical sessions reject further use.
- All package surfaces use 0.3.1. Analysis, output and changes schemas are
  unchanged.

The installed-wheel suites explicitly exercise these APIs on Windows and Linux.
Host qualification uses the unchanged CandleScope native/external/replay suite
in isolation, with the new core and a locally repinned adapter. It does not
activate a production host installation.

See [interface acceptance](../HOST_INTERFACES_ACCEPTANCE_20261007.md),
[external execution](../EXTERNAL_BROKER_V1.md) and
[historical sessions](../FIXED_HISTORY_SESSION.md). The 0.3.0 finite 216-trial
resource qualification remains evidence for that release, not a fresh resource
matrix for these interfaces. Full Pine/native live-tick parity and the earlier
unsupported platforms remain outside scope.
