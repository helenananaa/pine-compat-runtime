# Realtime `request.security_lower_tf` arrays (2026-09-25)

Provider-backed Pine v5/v6 `request.security_lower_tf()` requests now return arrays for forming and confirmed chart updates when the host supplies ordered intrabar updates through `RequestFeed`. The arrays contain only requested-context values through the latest observed intrabar in the current chart period, sorted by opening timestamp. No current-period feed update yields empty arrays, even if a static provider contains future rows. A feed update from a future chart period fails and rolls back the preview. Scalar and scalar-tuple expressions share this behavior; `calc_bars_count` truncates the full observed requested history before expression evaluation. The host still owns data acquisition and update ordering.

The Pine v6 runtime regression covers historical seed values, an empty forming chart bar, forming and confirmed intrabars, replacement of a forming intrabar at the same timestamp, tuple array lengths and values, a bounded cumulative expression and requested `bar_index`, rollback of a future-period update, and chart-bar confirmation. A Pine v5 regression confirms that static provider rows from the current period stay invisible until an ordered feed update arrives. The unbounded path uses the existing incremental requested-context evaluator when eligible; bounded expressions replay their capped history. This behavior follows TradingView's [intrabar array ordering and realtime guidance](https://www.tradingview.com/pine-script-docs/concepts/other-timeframes-and-data/).

Native TradingView v6 observation on COINBASE:BTCUSD daily chart, requesting hourly closes: the current chart bar showed `barstate.isrealtime = 1`, array length `12`, first value `84577.63`, and last value `84669.21`. Eight seconds later, length and first value were unchanged while the last value became `84677.35`. A closed chart bar showed realtime flag `0`, length `24`, first `78175.94`, and last `77665.14`. This confirms native script admission and the observable last-element update shape. The local regression uses synthetic host bars; same-feed numeric parity and the next-hour append transition have not been captured. Provider differences can repaint after reload.

The final locked seven-package test passed with 80 successful suites and no failures; the ignored log is `.local/community-coverage-20260923/security-lower-tf-realtime-seven-package-tests-20260925.log`. `cargo fmt --all -- --check` and `git diff --check` also passed.
