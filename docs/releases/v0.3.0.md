Stable release of the independently usable Pine runtime core for its named
compatibility scope.

### Changes

- Integrates incremental/realtime sessions, replica and public-result APIs.
- Corrects chart/request time behavior and validates bar timestamps atomically.
- Bounds logical per-bar collection/copy allocation and matrix work, with
  explicit `E_RESOURCE_BUDGET` errors.
- Reduces sparse rollback, collection/matrix scan and repeated lookup costs;
  caches immutable ALMA coefficients.
- Uses unique `0.3.0` identities across all package surfaces.

### Qualification and downloads

Fresh Windows/Linux optimized builds pass both canonical gates and the
unchanged fifteen-case compatibility plan: 180 complete outputs agree.
The complete fixed long-session resource matrix passes all 216 fresh trials
without changing workloads or budgets; 540 full outputs, 108 session isolation
comparisons and 180 historical controls agree.

Official assets are optimized Python wheels for ordinary GIL-enabled CPython
3.10+ on Windows x86-64 and glibc Linux x86-64 (manylinux2014 / glibc 2.17),
plus manifest and SHA-256 checksums. Clean offline wheel installations pass
all fifteen outputs, the embedding example and an independent SMA oracle.
Rust, CLI and WASM are available from the tagged source.

### Upgrade and limits

Handle timestamp rejection and `E_RESOURCE_BUDGET`. Defaults are 64 MiB logical
collection/copy bytes and 100,000,000 matrix work units per bar execution.
Rust exposes configurable limits; Python, CLI and WASM use defaults.

The resource qualification is a finite synthetic offline workload. Named
strategy cases are supported; arbitrary Pine/native live-Tick compatibility,
exchange-session calendars and native visual geometry remain outside scope.
Hull displayed-PnL residuals remain open (retained maximum 0.006690 USD).
macOS, ARM, musllinux and free-threaded CPython are outside the wheel matrix.

Read [migration and limits](https://github.com/helenananaa/pine-compat-runtime/blob/v0.3.0/docs/STABLE_MIGRATION.md)
and [acceptance evidence](https://github.com/helenananaa/pine-compat-runtime/blob/v0.3.0/docs/STABLE_ACCEPTANCE_20261006.md).
