Adds native macOS Python wheels for Apple Silicon and Intel alongside the
existing Windows x86-64 and glibc Linux x86-64 wheels.

- Each platform builds a release wheel, installs it, and runs the Python
  binding suite on its native GitHub-hosted runner before uploading the asset.
- New releases require four wheels plus `manifest.json` and `SHA256SUMS`.
  The manifest records the exact compatibility tags and SHA-256 digests.
- All Rust, CLI, WASM and Python package versions are 0.3.2. Runtime behavior,
  dependencies, host interfaces and output schemas are unchanged from 0.3.1.
- The request fixture's transcendental math assertions permit a one-ULP
  platform rounding difference, observed for `tan(0.1)` and `acos(0.5)` on
  macOS arm64. Series shape, NA placement, zeros, other numeric checks and
  resource budgets remain exact or retain their existing tolerances.
- macOS builds use standard `macos-15` (arm64) and `macos-15-intel` (x86-64)
  runners with Rust 1.95.0. The minimum macOS version is encoded in each wheel
  filename; installed-wheel tests validate the runner OS, not every older OS.

Download the wheel matching your architecture and install it into a virtual
environment. Ordinary GIL-enabled CPython 3.10 and newer is supported through
`abi3-py310`; free-threaded CPython and Linux/Windows ARM remain outside scope.

This is a packaging release. The earlier 0.3.0 resource matrix and 0.3.1 host
interface acceptance retain their original evidence boundaries; no new full
resource qualification or broader Pine compatibility is claimed.
