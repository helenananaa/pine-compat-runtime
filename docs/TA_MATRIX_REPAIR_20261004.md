# TA、HMA 与矩阵内核修复（2026-10-04）

比较基线 `35ae4e01277453401bbda34a4cfab5399715d5f4`：先冻结 6290 份源码与 501 份 release 产物，再修复；最终 6297 份源码同时用于 Windows/Linux 门禁。旧探针从上一轮最终 after 产物按原始字节继承，源码、库、可执行文件 SHA 均验证。

## 修复

- TA 的 67 处取参复用已验证的 RuntimeArgs 位置参数快路径；手写 HIR、命名覆盖、稀疏及复用 ID 仍走受验证的布局或原扫描。保留原始重载识别和参数求值顺序。
- HMA 半窗从完整窗的后缀计算，移除第二份窗口和 rollback 状态；权重与加法顺序保持一致。删除 RollingWindow 无消费者的平方和及对应 undo 写入。WMA/HMA 的加权扫描算法仍保留。
- pinv 投影与 eigenvectors 列归一化复用 scratch buffer，每次使用前完整覆写。QR 的近零列补 Q 基向量时保持 R 对角为零，避免虚构约 1 的特征值。
- 极小或极大特征值输入按二次幂缩放，只有每个元素逐位可逆时才启用；普通路径保留旧计算次序。rank 只在消元中出现非有限值后按行可逆缩放重试，不给普通调用分配备份。

## 资格边界与剩余问题

请求分配只计 allocator 请求，不含分配器开销；Windows RSS 为工作集，process peak 自启动累计。三样本描述性中位数不等于统计显著性或发布资格，单次 staged 的时间只能归因参考。

极端 eigen 只恢复 maxabs<=1e-12 或 >sqrt(MAX) 且每元素位可逆的子集；并非完整 f64 稳定性资格。rank 只恢复非有限消元且行缩放可逆、重试有限的子集。另有两个已实测保留的遗留反例：一行同时含 1e308/1e-308 的 4×4 满秩矩阵，缩放不可逆时仍 rank=3（解析为4）；maxabs=1e154 的下三角矩阵，其列平方和可溢出但未触发 extreme guard。具体旧/新输出见 JSON 限制诊断，不能把通过本轮测试解释为这些问题已经解决。
