Adds native macOS Apple Silicon and Intel wheels to the GitHub Actions release
matrix. Linux x86-64 and Windows x86-64 wheels remain available.

- Each of the four jobs installs its own release wheel and runs the complete
  Python binding suite before uploading it. Publication requires all four jobs.
- macOS builds use native `macos-15` / `macos-26-intel` runners and Rust 1.95.0.
  The minimum macOS version is recorded in each wheel's compatibility tag.
- All nine crate versions, Python packaging and binding version assertions
  advance together to 0.3.2. Runtime implementation and schemas are unchanged
  from v0.3.1; `run_external` and `historical_session` remain available.
- Releases include four wheels, `manifest.json` and `SHA256SUMS`. Hosts must
  choose a compatible wheel and verify its digest before installation.

This is a platform-packaging release. Existing 0.3.0 resource qualification and
0.3.1 interface evidence keep their original source pins; this release does not
claim a new resource matrix or completed CandleScope macOS UI qualification.
