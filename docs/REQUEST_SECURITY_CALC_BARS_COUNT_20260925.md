# Bounded `request.security` history (2026-09-25)

Modern Pine v5/v6 `request.security()` now accepts named simple-int `calc_bars_count` after the three positional selector/expression arguments, with or without supported `gaps` and `lookahead` options. A positive value retains the most recent N requested bars before expression execution. Zero uses all available bars, matching TradingView's [May 2024 release note](https://www.tradingview.com/pine-script-docs/release-notes/). The parameter occupies the eighth position in the [official `request.security` signature](https://www.tradingview.com/pine-script-docs/concepts/other-timeframes-and-data/); other optional parameters remain outside the admitted subset.

The tracked `security_calc_bars_count.pine` fixture requests `[ta.cum(close), bar_index]` with explicit gap and lookahead policies. Runtime tests verify the cumulative state and requested `bar_index` restart at the retained history origin, earlier chart bars return `na`, zero uses the full dataset, and same-context tuple fields remain accessible after the bound. A CLI run on the tracked one-minute chart and IBM request CSVs produced `[[null,null,null,23,47],[null,null,null,0,1]]` with no diagnostics; the JSON is retained in ignored `.local/community-coverage-20260923/security-calc-cli-20260925.json`. The host still supplies the requested bars; the core applies the limit deterministically.

Native TradingView v6 check on COINBASE:BTCUSD daily chart: an unsaved indicator requested `[ta.cum(close), bar_index]` from `syminfo.tickerid` / `timeframe.period` with `calc_bars_count=3`. Its first two retained, closed bars displayed `(84378.31, 0)` and `(168763.77, 1)`, with chart closes `84378.31` and `84385.46`. A local CLI run of the same expression over those closes, with an earlier sentinel bar, returned `na` before the limit and the same two pairs (allowing floating-point display rounding). The third native bar was forming, so its changing value was excluded from the numerical comparison. Local oracle input and output are retained in ignored `.local/community-coverage-20260923/security-calc-tv-*`. This check exposed and led to a fix for the same-context `bar_index` reset. Bounded same-context calls must execute on every retained chart bar; skipped calls fail explicitly because the runtime cannot reconstruct omitted chart bars from that call site.

This does not yet qualify the public TradingView `ta` library. Its request helpers also use dynamic `series string` timeframe selectors, tick-based paths, and other library dependencies that remain unsupported. The final locked seven-package test result is retained in ignored `.local/community-coverage-20260923/security-calc-seven-package-tests-final-20260925.log`.
