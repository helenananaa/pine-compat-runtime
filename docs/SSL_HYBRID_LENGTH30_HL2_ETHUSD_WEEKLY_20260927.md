# SSL Hybrid Strategy HMA 30 with HL2 on ETHUSD weekly history (2026-09-27)

The unchanged public Pine v5 [SSL Hybrid Strategy by kevinmck100](https://www.tradingview.com/script/2it69GUx-SSL-Hybrid-Strategy/) was run in Chrome on `COINBASE:ETHUSD`, `1W`. `SSL1 / Baseline Type` was `HMA`, `SSL1 / Baseline Length` was 30, and `Source` was `(H + L)/2` (`hl2`). All other script inputs and the Properties settings retained their original values. The frozen 557-line source in `.local/ssl-hybrid-length30-hl2-ethusd-weekly-20260927/ssl-hybrid-original.pine` has SHA-256 `1b90bead338682dcc17b8c1063637e7b8354c91b35d9d2a741ae41b5274c658c`. The same ignored directory retains the TradingView Inputs and Properties panels, screenshot, chart CSV, and List of trades CSV. Properties show USD 5,000 initial capital, 10% equity default order size, pyramiding 10, 0.04% commission, zero slippage, default four-tick historical bar detail, and one-tick order delay.

The first TradingView chart export contained only 300 rows starting in late 2020, because the chart had not loaded its earlier history. The chart's Custom range was expanded to start at 2016-05-23 and exported again. The frozen full chart CSV (`native-chart.csv`, SHA-256 `4f70737f4f9408456042d8ea6a17fc2c669b4c6355582c90169652b96fe8fb51`) has 540 rows from 2016-05-23 through the forming 2026-09-21 week. The forming row was excluded, leaving **539 confirmed weekly bars through 2026-09-14**. Time and OHLC agree with the independently exported [close-source comparison](SSL_HYBRID_LENGTH30_ETHUSD_WEEKLY_20260927.md). The final confirmed week's volume was revised from `917799.38115157` to `917824.4968639`, so the local run uses the new export's bars throughout. `bars-receipt.json` records the files, row counts, revision, and hashes. The native trade CSV hashes to `213c132100cff43c5722746710456c7ea903c0e6b7a8049350e23169314a5f03`.

All **3,599 nonblank positions** in the eight exported indicator series match locally at `1e-8` absolute tolerance. The optional second moving average is blank. TradingView's chart export flattens the Candle Size false/`na` condition to zero, and the comparator applies that export interpretation. The native report contains **98 closed trades and two open entries**. Every closed trade's entry ID, UTC entry and exit date, displayed entry and exit price, and quantity matches the local result. The two open entries match in ID, date, displayed entry price, and quantity. The maximum closed net-PnL difference is `$0.004995`, within cent display precision. There are no runtime diagnostics.

With `close` and `hl2` evaluated on the **same newly frozen bars**, all 506 upper-channel and all 506 lower-channel values change, while the strategy orders and trades are identical. The two TradingView exports also have identical 98 closed-trade records. Their open-trade unrealized PnL differs because the forming week's market price changed between downloads. This parameter combination therefore exercises source-input and channel semantics without creating a distinct historical trade path.

The host-neutral chart contract supplies symbol, weekly timeframe, a `1/100` price grid, and four-decimal quantity precision. CLI input callsites 13 and 18 are overridden with `30` and `hl2`. Batch, incremental, and realtime-history JSON are byte-identical, SHA-256 `bd114333df900606b5b01754e5a6d83f4e52ec5a8f66161c314d3731997a7084`. No runtime repair was needed for this slice. The evidence qualifies confirmed historical weekly bars for this source, symbol, and setting; it does not establish forming-bar or live-tick parity.

Reproduce from the repository root:

```powershell
python .local/ssl-hybrid-length30-hl2-ethusd-weekly-20260927/prepare_bars.py
target/debug/pine-compat.exe run .local/ssl-hybrid-length30-hl2-ethusd-weekly-20260927/ssl-hybrid-original.pine --bars .local/ssl-hybrid-length30-hl2-ethusd-weekly-20260927/bars-confirmed.csv --chart-symbol COINBASE:ETHUSD --chart-timeframe 1W --chart-price-grid 1/100 --chart-quantity-precision 4 --input-override 13=30 --input-override 18=hl2 > .local/ssl-hybrid-length30-hl2-ethusd-weekly-20260927/local-batch.json
python .local/ssl-hybrid-length30-hl2-ethusd-weekly-20260927/compare.py
python .local/ssl-hybrid-length30-hl2-ethusd-weekly-20260927/verify_modes.py
```

For `verify_modes.py`, run the same command with `run-incremental` and `run-realtime-history`, writing `local-run-incremental.json` and `local-run-realtime-history.json`. It also compares `local-close-control.json`, made with the same `run` command but without `--input-override 18=hl2`.
